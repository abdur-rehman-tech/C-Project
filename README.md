# 🎮 Skoudo Word Game (C++)

![C++](https://img.shields.io/badge/C++-00599C?style=flat-square&logo=cplusplus&logoColor=white)

A console word-guessing game in C++. Guess the hidden word letter by letter before you run out of **6 wrong tries**.

## 🚀 Build & run

```bash
g++ game.cpp -o game
./game
```

## 🧠 Concepts

Arrays and C-strings, loops and conditionals, tracking guessed letters, game state.
